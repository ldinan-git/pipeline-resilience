How Tier 3 resolves incidents

1. New quarantine batch arrives — violations are normalized and embedded.
2. Embedding is compared against every resolved incident in this table using cosine similarity.
3. If similarity > 0.85, the stored fix is returned as the Tier 3 suggestion.
4. If similarity > 0.92, the fix is applied automatically — no human needed.
The more incidents your org resolves, the more Tier 3 handles automatically. Tier 5 (raw LLM) becomes a last resort.

Production path

Currently running locally — the corpus is in your SQLite database, similarity computed in Python.
In production, set CORPUS_API_URL to point at the central hosted corpus. The same lookup() and contribute() calls work unchanged — they just route to the remote API instead of local SQLite.
The hosted corpus uses pgvector for efficient similarity search across millions of entries, filtered by industry vertical so financial services firms match against financial services patterns first.

Learn Validation Rules from Known-Good Data

Provide a sample of correct, verified output data. The LLM analyzes column statistics — valid ranges, valid enum values, null rates — and generates validation rules with fix policies. These rules run before every pipeline execution, so the pipeline only ever sees clean data.

First run: python generate_good_sample.py to create a clean reference dataset.
Switch to Validation Rules to review.

How it works

1. Learn — Provide known-good output data. LLM reads column statistics and generates rules (valid ranges, valid enum codes, required fields) plus a default fix policy for each.
2. Validate — On every pipeline run, raw data is checked against these rules before the pipeline sees it.
3. Auto-fix & quarantine — Rows with known violations are auto-fixed in place. Rows with unknown violations are split into a quarantine batch. The pipeline runs immediately on the clean portion.
4. Triage — The LLM analyzes quarantined rows and suggests fix policies. Accepted fixes update the rule permanently, so future occurrences are handled automatically without human review.
